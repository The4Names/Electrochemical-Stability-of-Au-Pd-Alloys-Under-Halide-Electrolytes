# Electrochemical-Metastability-of-Au-Pd-Alloy-Nanoparticles-under-Halide-Induced-Dissolution-
In this repository, you will find the database containing all the DFT-optimized structures of Au₀.₂₀Pd₀.₈₀ surfaces used to analyze the stability of the Au–Pd alloy under different halide environments (HCl, HBr, and HI).
